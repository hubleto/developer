# Insurance CRM

Following set of prompts was used to generate a simple insurance CRM app.

More details can be found [here](https://dev.to/shoki_ztk/vibe-coding-custom-insurance-crm-in-less-than-a-day-cf).

## Prompt 1

```
Study on web what data structures and processes should be covered by CRM for insurance companies.
```

## Prompt 2

```
Identify processes already implemented in Hubleto community apps.
```

## Prompt 3

```
Create one or more Hubleto custom apps to cover missing processes and data structures.
```

## Prompt 4

```
Integrate new custom app with following community apps: Customers, Contacts, Calendar and Workflow.
```

## Prompt 5

```
Add reasonable statistics in the home page of new custom app.
```

## Prompt 6

```
Redesign Home.twig view for more modern look.
```

## Prompt 7

```
Create one dashboard per each model in new custom app showing total number of items in that model.
```
