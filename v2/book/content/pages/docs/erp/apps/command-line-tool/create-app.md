# Using php hubleto create app

## Purpose

`php hubleto create app` generates the skeleton of a new app: manifest, loaders, a home page, a settings page, a calendar class and an app menu extendible. Then it offers to install the app.

```bash
php hubleto create app MyFirstApp
```

`create app` is a synonym for `php hubleto app create`.

## Syntax

```
php hubleto create app <appNamespace> [noPrompt]
```

| Argument         | Description                                                                          |
| ---------------- | ------------------------------------------------------------------------------------ |
| `appNamespace`   | `MyFirstApp` (short) or `Hubleto\App\Custom\MyFirstApp` (full).                      |
| `noPrompt`       | Any non-empty value: install the app without asking.                                 |
Arguments.

Where the app is created depends on the third part of the namespace:

| Namespace                                 | Folder                                                    |
| ----------------------------------------- | --------------------------------------------------------- |
| `Hubleto\App\Custom\MyFirstApp`           | `<project>/src/apps/MyFirstApp` (folders are created)     |
| `Hubleto\App\Community\MyFirstApp`        | `vendor/hubleto/erp/apps/MyFirstApp` (for contributors)   |
| `Hubleto\App\External\Acme\MyFirstApp`    | folder configured in `externalAppsRepositories` for `Acme` |
| `Hubleto\App\Premium\...`                 | not implemented                                           |
Target folders.

## Generated files

```
src/apps/
└── MyFirstApp/
    ├── Controllers/
    │   ├── Home.php          # home page of the app
    │   └── Settings.php      # settings page of the app
    ├── Extendibles/
    │   └── AppMenu.php       # app menu items (commented out)
    ├── Views/
    │   ├── Home.twig
    │   └── Settings.twig
    ├── Calendar.php          # calendar skeleton (not registered)
    ├── Loader.php            # routes, settings tile, installApp(), generateDemoData()
    ├── Loader.tsx            # instructions and markers for React components
    └── manifest.yaml
```

The files are rendered from the templates in `vendor/hubleto/erp/cli/Templates/app/`.

###### manifest.yaml

```yaml
namespace: Hubleto\App\Custom\MyFirstApp
appType: custom
monthlyPricePerUser: 0
sidebarGroup: custom
rootUrlSlug: myfirstapp
name: MyFirstApp
icon: fas fa-home
author:
  name: "Hubleto CLI Agent"
  nick: "hubleto.cli"
highlight: App generated by Hubleto CLI agent.
created: 2026-09-30 12:41:14
```

The `rootUrlSlug` is the app name converted with `Helper::str2url()`: `MyFirstApp` becomes `myfirstapp`.

###### Controllers/Home.php

```php
<?php

namespace Hubleto\App\Custom\MyFirstApp\Controllers;

class Home extends \Hubleto\Erp\Controller
{
  public function getBreadcrumbs(): array
  {
    return array_merge(parent::getBreadcrumbs(), [
      [ 'url' => 'myfirstapp', 'content' => 'MyFirstApp' ],
    ]);
  }

  public function prepareView(): void
  {
    parent::prepareView();
    $this->viewParams['now'] = date('Y-m-d H:i:s');
    $this->setView('@Hubleto:App:Custom:MyFirstApp/Home.twig');
  }
}
```

###### Controllers/Settings.php and Views/Settings.twig

```php
class Settings extends \Hubleto\Erp\Controller
{
  public function getBreadcrumbs(): array
  {
    return array_merge(parent::getBreadcrumbs(), [
      [ 'url' => 'myfirstapp', 'content' => 'MyFirstApp' ],
      [ 'url' => 'settings', 'content' => 'Settings' ],
    ]);
  }

  public function prepareView(): void
  {
    parent::prepareView();
    $this->setView('@Hubleto:App:Custom:MyFirstApp/Settings.twig');
  }
}
```

## Next steps

  2. Add a table and a form: [`php hubleto create mvc MyFirstApp Book`](create-mvc).

  4. Choose a proper `icon` and `sidebarGroup` in `manifest.yaml`.
  5. If the app has its own events, uncomment and implement the calendar ([Calendar integration](../integrations/calendar)).
